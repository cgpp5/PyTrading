# Get paid out dividends

Rate limit: 6 req / 1m0s

Endpoint: GET /api/v0/equity/history/dividends
Version: v0
Security: authWithSecretKey, legacyApiKeyHeader

## Query parameters:

  - `cursor` (integer)
    Pagination cursor

  - `ticker` (string)
    Ticker filter

  - `limit` (integer)
    Max items: 50
    Example: 21

  - `items.instrument` (object)

  - `items.instrument.name` (string)
